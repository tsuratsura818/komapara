## 1. サービス概要

| 項目 | 内容 |
|------|------|
| サービス名 | **コマパラ**（Komapara） |
| URL | https://komapara.com |
| ジャンル | 4コマ漫画ポータルサイト |
| ポジション | 4コマ漫画に特化した「読む・描く・つながる」プラットフォーム |

### ワンライナー
> 4コマの世界を、もっと楽しく。

### エレベーターピッチ
XやInstagramに散らばる4コマ漫画を一箇所に集め、読者には「いつでもサクッと楽しめる4コマ体験」を、クリエイターには「作品を届ける場所と収益化の手段」を提供するプラットフォームです。

---

## 2. 解決する課題

### 読者側の課題
| 課題 | 現状 | コマパラの解決策 |
|------|------|----------------|
| 4コマが見つけにくい | XのTLに流れて消える、検索性が低い | ジャンル別・ランキング・検索で発見できる |
| まとめて読めない | 作家のアカウントを巡回する必要がある | フォロー機能＋フィードで自動集約 |
| 読み返せない | TLを遡るしかない | ライブラリ（いいね・閲覧履歴）で管理 |
| シリーズものを追いにくい | 投稿が時系列で埋もれる | シリーズ機能で前後ナビ付き連載管理 |

### クリエイター側の課題
| 課題 | 現状 | コマパラの解決策 |
|------|------|----------------|
| 収益化が難しい | XだけではFANBOX等への導線が弱い | 会員費を閲覧数で配分するクリエイター還元を提供 |
| 投稿が手間 | プラットフォームごとに再投稿が必要 | X/Instagram連携で1タップインポート |
| リーチが限定的 | フォロワー依存、新規に届きにくい | ランキング・ジャンル別・おすすめで新規読者に露出 |
| 反応が見えにくい | いいね数だけでは感情が伝わらない | 5種リアクション＋コメントで具体的フィードバック |

## 3. ターゲットユーザー

### プライマリ：読者（20〜40代・スマホユーザー）
- 通勤・通学のスキマ時間に手軽なコンテンツを楽しみたい
- Xで4コマを見るのが好きだが、探しにくいと感じている
- お気に入りの作家を応援したい気持ちがある

### セカンダリ：クリエイター（4コマ漫画家・イラストレーター）
- XやInstagramで4コマを投稿している個人作家
- 自分の作品を多くの人に届けたい
- 創作活動で少しでも収益を得たい

## 4. サービスコンセプト

### 3つの柱

```
┌─────────────────────────────────────────────┐
│                                             │
│   📖 読む    ✏️ 描く    🤝 つながる        │
│                                             │
│   多彩な     4枚の画像   いいね             │
│   クリエイ   アップロード コメント           │
│   ターの     だけで簡単   フォローで          │
│   4コマを    に公開      作家と読者が        │
│   楽しめる               つながる            │
│                                             │
└─────────────────────────────────────────────┘
```

### 体験フロー

**読者の体験:**
```
サイト訪問 → フィードで4コマ発見 → 作品を読む → リアクション
    ↓              ↓                              ↓
ジャンル探索   ランキングで人気作発見         作家フォロー
    ↓              ↓                              ↓
ライブラリ保存  新着通知で継続訪問          会員登録で応援
```

**クリエイターの体験:**
```
X/Instagramで4コマ投稿 → コマパラに1タップ連携 → 読者にリーチ
                                                      ↓
ダッシュボードで反応確認 ← クリエイター還元で収益化 ← ファン獲得
```

## 5. 主要機能

### 読者向け機能

| 機能 | 説明 | 差別化ポイント |
|------|------|---------------|
| **フィード** | 新着・人気・フォロー中の3タブ、無限スクロール | SSRで初回表示高速化済み |
| **ジャンル別閲覧** | 日常/ギャグ/育児/猫/仕事/恋愛/感動/エッセイ | 4コマ特化のジャンル設計 |
| **4コマビューワー** | ダーク背景で没入感、縦スクロール表示 | 4コマに最適化されたUI |
| **5種リアクション** | ❤️いいね/😂笑った/😢泣いた/🤝共感/✨すごい | 「いいね」以上の感情表現 |
| **週間ランキング** | 毎週月曜集計、TOP20表示 | 新しい作品との出会い |
| **検索** | 作品名・作家名でキーワード検索 | - |
| **マイライブラリ** | いいね履歴＋閲覧履歴の一元管理 | 読み返し体験の向上 |
| **シリーズ閲覧** | 前後ナビ付き連載読み | 連載ものを見失わない |
| **プッシュ通知** | フォロー中作家の新作をリアルタイム配信 | ブラウザを開いていなくても受け取れる |
| **プレミアム** | 月額300円で広告非表示 | 快適な読書体験 |

### クリエイター向け機能

| 機能 | 説明 | 差別化ポイント |
|------|------|---------------|
| **かんたん投稿** | 画像ドラッグ&ドロップ＋情報入力のウィザード形式 | 最短30秒で投稿完了 |
| **X自動連携** | X投稿URLから画像を自動取得してインポート | XのTLを複製する手間ゼロ |
| **Instagram連携** | Instagram投稿から画像を自動取得 | 複数SNSからの集約 |
| **バッチインポート** | Xの最新投稿を一括で同期 | 過去の投稿もまとめて移行 |
| **シリーズ管理** | 連載の作成・話数管理・完結設定 | 長期連載のハブとして機能 |
| **ダッシュボード** | 閲覧数/いいね/フォロワー/収益を一覧表示 | 創作のモチベーション維持 |
| **クリエイター還元** | 読まれた分だけ収益に（会員費を閲覧数で配分・準備中） | 読者が増えるほど作家に還元 |
| **プレミアム会員** | 広告非表示＋クリエイター支援（準備中） | 読者の月額支援がそのまま作家へ |

## 7. マネタイズ（収益モデル）

### 収益構造

```
┌──────────────────────────────────────────────────┐
│              コマパラの収益源                      │
├──────────────────────┬───────────────────────────┤
│  広告収入(AdSense)    │  プレミアム会員（月額300円） │
│                      │                            │
│  フィード内・作品詳細  │  会員費の一部を運営費に、    │
│                      │  残りを閲覧数に応じて        │
│  全ユーザー対象       │  クリエイターへ配分          │
└──────────────────────┴───────────────────────────┘

※ 投げ銭・個別サブスクは提供しない（決済審査・運用リスクを避けるため）
※ クリエイター還元は「読者→作家の直接送金」ではなく、
   コマパラが会員費を集約し、閲覧数シェアに応じて配分（YouTube/Spotify型）
```

## 8. 技術構成

| レイヤー | 技術 |
|----------|------|
| フロントエンド | Next.js 14 (App Router) + TypeScript + Tailwind CSS |
| バックエンド | Next.js API Routes + Prisma ORM |
| 認証 | NextAuth.js v5（Google / X / Magic Link） |
| データベース | PostgreSQL（Supabase） |
| ストレージ | Vercel Blob（画像保存、WebP自動変換） |
| ホスティング | Vercel（自動デプロイ、エッジ配信） |
| プッシュ通知 | Web Push API + VAPID |
| PWA | Service Worker + manifest.json |

### パフォーマンス最適化
- ISR（Incremental Static Regeneration）でページキャッシュ
- ホームページはSSRで初期データを取得し即座に表示
- 全ルートにloading.tsxスケルトンUIを配置
- 画像はWebP変換＋next/imageで自動最適化

## 12. まとめ

コマパラは「4コマ漫画」というニッチだが根強い人気を持つコンテンツに特化することで、既存の汎用プラットフォームでは満たせない「読みたい4コマがすぐ見つかる」「描いた4コマがすぐ届く」という体験を実現します。

SNS連携によるゼロコスト投稿、5種リアクションによる豊かなフィードバック、会員費を閲覧数で配分するクリエイター還元を一体化し、**読者とクリエイターの好循環**を生み出すプラットフォームを目指します。
