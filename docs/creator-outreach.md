## DM送信のコツ

### やるべきこと
- **相手の作品に具体的に触れる**（「○○の回が特に好きです」など）
- **1日10〜15通が安全ライン**（急に大量送信するとアカウント制限）
- **相手のプロフィールをチェック**（DM開放しているか確認）
- **先にいいね・RTで存在を認知してもらう**（DM前に数日間）
- **返信がなくても2回目は送らない**

### やってはいけないこと
- コピペ感丸出しのDM（必ず個人名・作品名をカスタマイズ）
- 短期間での大量送信（スパム判定リスク）
- 返信催促・しつこいフォローアップ
- フォロワー数が多すぎる人（10万+）への営業DM

### 効果的な順序
1. まず相手の作品をいくつか「いいね」する（2〜3日）
2. 特に好きな作品をRTやリプライで反応する
3. 認知された頃にDMを送る
4. 返信があれば丁寧に対応、なければそのまま

### 探し方のTips

上記は調査で見つかったアカウントですが、**最も効果的なのはXで直接ハッシュタグ検索すること**です：

1. Xで `#4コマ漫画` を検索 → 「最新」タブに切り替え
2. 直近1週間以内に投稿しているアクティブなクリエイターをピックアップ
3. プロフィールでフォロワー数を確認（1,000〜50,000がDM反応率が高い）
4. DM開放しているか確認（鍵アイコンがない＋DMボタンが表示される）
5. リストに追加して、数日いいね→DMの順序で進める

**特に狙い目のキーワード:**
- `#4コマ漫画 min_faves:10 min_retweets:3` （一定の反応がある投稿者）
- `#育児漫画 -filter:verified` （認証済みでない中規模アカウント）
- `#猫漫画` `#犬漫画` `#ペット漫画` （ペット系コミュニティ）
- `#エッセイ漫画` `#コミックエッセイ` （書籍化志向の作家多め）
- `#日常漫画` `#漫画が読めるハッシュタグ` （幅広いジャンル）
