# UIデザインガイドライン

## デザイン原則

1. **読者体験最優先** — 4コマを「読む」体験を邪魔しない。UIは引き算でシンプルに。
2. **モバイルファースト** — スマホ375px幅を基準に設計。PCは375px以上のレイアウト調整。
3. **コンテンツ密度の最適化** — フィードは1画面に2〜3作品が見えるカード型。スクロールが楽しくなるリズム感。
4. **広告との共存** — 広告はコンテンツの邪魔にならない位置に。作品閲覧中に割り込まない。

## 広告スペースの実装

開発環境ではグレーのプレースホルダーを表示：

```tsx
// components/ui/AdsenseUnit.tsx
export function AdsenseUnit({ slot }: { slot: string }) {
  if (!process.env.NEXT_PUBLIC_ADSENSE_ID) {
    return (
      <div className="w-full bg-gray-100 border border-dashed border-gray-300 rounded flex items-center justify-center text-gray-400 text-sm"
           style={{ minHeight: 100 }}>
        広告スペース（{slot}）
      </div>
    );
  }
  // 本番: Google AdSense スクリプト
  return <ins className="adsbygoogle" data-ad-slot={slot} />;
}
```

## アニメーション

- ページ遷移: Fade（`opacity` 0→1、150ms）
- カードホバー: `scale(1.01)`（100ms）
- いいねボタン: ハートの弾むアニメーション（`scale` 1→1.3→1、200ms）
- フィード読み込み: スケルトンローディング（`animate-pulse`）
