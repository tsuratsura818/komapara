# コマパラ キービジュアル用 ChatGPTプロンプト

## ⚠️ 使う前に必ず読んでください

**ChatGPTはアオンを知りません。** 文章だけで描かせると別のキャラが出ます。

**必ず「アオンが大きく写っている画像を1〜2枚添付」してから、下のプロンプトを貼ってください。**
（例：コマパラの作品ページからアオンの絵をスクショ／IGの投稿画像）

添付なしで使うと「水色の狼」程度の別物が出てきて、ブランドとして使えません。

---

## プロンプト①：SNSヘッダー（X用 1500×500）

```
添付した画像のキャラクター「アオン」（おくり狼のアオン）を使って、Webサービスのヘッダー画像を作ってください。

【最重要】
添付画像の絵柄・キャラクターデザインを厳密に踏襲してください。特に以下は絶対に変えないでください：
- 淡いミントブルー〜グレーがかった水色の毛並みの狼
- 眠そうな半目（ジト目）。目つきは鋭いが表情は柔らかい
- 黄色い蝶ネクタイ（リボンタイ）
- オレンジ色のベスト
- 太くてやや不揃いな手描きの黒い輪郭線（デジタルの均一な線ではない）
- 平坦な塗り（グラデーションや陰影をほとんど使わない）
- 淡くくすんだパステル調の配色

【サービス】
「コマパラ」— 4コマ漫画だけが集まるポータルサイト

【構図】
- 横長 3:1（1500×500px想定）
- 左側にアオンが1体、こちらを見て静かに佇んでいる（全身または上半身）
- 右側〜中央に、4コマ漫画の「コマ割り」を思わせる白い枠が数個、軽やかに浮かんでいる（中身は空でよい）
- 背景は淡い青（#2563eb を薄めた水色〜白のグラデーション、または白地に薄い青の格子）

【トーン】
静かで、清潔で、やさしい。にぎやかにしない。作品が主役なので、キャラも背景も出しゃばらない。

【禁止】
- 文字・ロゴ・タイトルを一切入れない（後からデザイン側で載せます）
- 写実的・3D・厚塗り・アニメ塗りにしない
- 派手なエフェクト、キラキラ、集中線を入れない
- 紫・ピンク・赤などの色を使わない（青とアオンの固有色のみ）
```

## プロンプト②：サイトトップ用（横長ワイド）

```
添付した画像のキャラクター「アオン」（おくり狼のアオン）を使って、Webサイトのトップに置くメインビジュアルを作ってください。

【最重要】
添付画像の絵柄・キャラクターデザインを厳密に踏襲してください。特に以下は絶対に変えないでください：
- 淡いミントブルー〜グレーがかった水色の毛並みの狼
- 眠そうな半目（ジト目）
- 黄色い蝶ネクタイ、オレンジ色のベスト
- 太くてやや不揃いな手描きの黒い輪郭線
- 平坦な塗り、淡くくすんだパステル調

【サービス】
「コマパラ」— 4コマ漫画だけが集まるポータルサイト。読者が4コマを読む場所であり、作家が作品を置く場所。

【構図】
- 横長 16:5 程度
- 中央〜右にアオンが1体。喫茶店のマスターなので、カウンター越しに読者を迎えるような佇まいでもよい
- 4コマのコマ割りを思わせる白い枠が、紙のように軽く浮かんでいる
- 余白を大きく取る。要素を詰め込まない
- 背景は白〜ごく淡い青。うるさくしない

【トーン】
静かで、清潔で、やさしい。「ここは読む場所だ」と伝わる落ち着き。

【禁止】
- 文字・ロゴを入れない
- 写実的・3D・厚塗りにしない
- 派手なエフェクト、キラキラを入れない
- 紫・ピンク・赤を使わない
```

## プロンプト③：企画書の表紙用（客先・パートナー向け）

```
添付した画像のキャラクター「アオン」（おくり狼のアオン）を使って、事業企画書の表紙に載せるビジュアルを作ってください。

【最重要】
添付画像の絵柄・キャラクターデザインを厳密に踏襲してください：
- 淡いミントブルー〜グレーがかった水色の毛並みの狼
- 眠そうな半目（ジト目）
- 黄色い蝶ネクタイ、オレンジ色のベスト
- 太くてやや不揃いな手描きの黒い輪郭線、平坦な塗り、淡いパステル調

【用途】
「コマパラ」（4コマ漫画ポータル）の事業企画書の表紙。取引先・パートナー企業に見せるもの。
可愛さより「きちんとした事業である」という信頼感を優先する。

【構図】
- 横長 16:9
- アオンは小さめ・端に配置。主役にしない
- 4コマのコマ割りを思わせる白い枠を、整然と（グリッド状に）配置する
- 余白を大きく、静かに。ビジネス文書の表紙として成立する落ち着き

【トーン】
清潔・端正・信頼感。子ども向けに寄せない。

【禁止】
- 文字・ロゴを入れない
- 賑やかな装飾、キラキラ、集中線
- 紫・ピンク・赤
```

## 補足：うまくいかないときの追加指示

**キャラが似ていないとき**
```
キャラクターが添付画像と違います。添付画像のアオンを、線の太さ・目つき・配色まで含めてそのまま再現してください。新しくデザインし直さないでください。
```

**絵が派手・うるさいとき**
```
装飾を減らしてください。背景をもっとシンプルに、余白を増やしてください。主役は静けさです。
```

**塗りが厚い・3Dっぽいとき**
```
平坦な塗りにしてください。陰影・グラデーション・立体感を使わず、フラットな色面と手描きの黒い輪郭線だけで描いてください。
```
