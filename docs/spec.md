## 2. 画面仕様詳細

### 2-1. ホーム（フィード）`/`

**タブ切り替え:**
- `新着順`（デフォルト）: `createdAt` DESC
- `人気順`: `likeCount` DESC（直近7日間）
- `フォロー中`: ログインユーザーのフォロー中の作家の新着（ログイン必須）

**作品カード（WorkCard）の表示要素:**
- 1コマ目のサムネイル画像
- タイトル
- 作家名 + アバター
- いいね数
- 投稿日時（相対時間: "3時間前"）
- ジャンルタグ（最大2つ表示）

**広告配置:**
- 5件ごとに1つ AdSense ユニット挿入

**無限スクロール:**
- 初回: 20件取得
- スクロール下部到達時: 追加20件取得
- `Intersection Observer` で実装

### 2-3. 週間ランキング `/ranking`

**表示内容:**
- 集計期間（"2026年2月第3週"）
- TOP 20 リスト
  - 順位（1位は大きく強調表示）
  - 作品サムネ
  - タイトル・作家名
  - スコア（いいね数・閲覧数も表示）

**更新タイミング:** 毎週月曜日 00:00 JST

---

### 2-4. 作品投稿 `/upload`

**STEP 1: 画像アップロード**
- 4つのドロップゾーンを縦に配置（コマ1〜4）
- ドラッグ&ドロップ または クリックでファイル選択
- 対応形式: JPEG / PNG / WebP
- 最大サイズ: 1ファイルあたり 5MB
- アップロード後プレビュー表示（差し替え可能）

**STEP 2: 作品情報入力**
- タイトル（必須・最大50文字）
- 説明（任意・最大200文字）
- ジャンルタグ（複数選択可・最大3つ）
  - 日常 / ギャグ / 育児 / 猫 / 仕事あるある / 恋愛 / 感動 / エッセイ
- Xへの自動シェア（ON/OFFトグル）

**STEP 3: 確認・投稿**
- プレビュー表示
- 「投稿する」ボタン
- 投稿完了後 → 作品詳細ページへリダイレクト

## 3. API仕様

詳細は `docs/api-spec.md` を参照。

### 主要エンドポイント一覧

| Method | Endpoint | 説明 | 認証 |
|--------|----------|------|------|
| GET | `/api/works` | 作品一覧（クエリ: `sort`, `genre`, `page`） | 不要 |
| GET | `/api/works/[id]` | 作品詳細 | 不要 |
| POST | `/api/works` | 作品投稿 | 必須 |
| DELETE | `/api/works/[id]` | 作品削除（本人のみ） | 必須 |
| POST | `/api/likes/[workId]` | いいね追加 | 必須 |
| DELETE | `/api/likes/[workId]` | いいね取り消し | 必須 |
| POST | `/api/follows/[userId]` | フォロー | 必須 |
| DELETE | `/api/follows/[userId]` | フォロー解除 | 必須 |
| GET | `/api/ranking/weekly` | 週間ランキング取得 | 不要 |
| GET | `/api/creators/[id]` | 作家プロフィール + 作品一覧 | 不要 |
| GET | `/api/search` | 検索（クエリ: `q`, `type`） | 不要 |
| GET | `/api/og/work/[id]` | OGP画像生成 | 不要 |
| POST | `/api/cron/weekly-ranking` | ランキング集計バッチ | Cron認証 |

## 4. 非機能要件

### パフォーマンス
- フィードの初回表示: LCP 2.5秒以内
- 画像: WebP変換 + CDN配信
- フィード一覧: ISR（revalidate: 60秒）で静的化
- 作品詳細: ISR（revalidate: 300秒）

### SEO
- 全ページ適切なメタタグ設定
- 作品詳細・作家ページは SSG または ISR
- サイトマップ自動生成（`/sitemap.xml`）
- robots.txt 設定

### アクセシビリティ
- 4コマの各コマに alt テキスト
- キーボードナビゲーション対応
- カラーコントラスト比 4.5:1 以上

### セキュリティ
- アップロード画像の Content-Type 検証
- Rate limiting（API Routes: IP ベース）
- CSRF 対策（NextAuth 標準機能）
- XSS 対策（dangerouslySetInnerHTML 禁止）
